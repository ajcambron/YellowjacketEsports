# Editing This Site

Every page is a Markdown file in the `docs/` folder of the repo.

**Quick edit:** click the pencil icon at the top of any page, make the change on GitHub, and commit to `main`. The site rebuilds in about a minute.

**Add a page:** create a new `.md` file in `docs/`, then add it to the `nav:` list in `mkdocs.yml`.

**Preview locally:**

```bash
pip install mkdocs-material
mkdocs serve
```

!!! warning
    This site is public. No student names, IDs, grades, or contact info.
